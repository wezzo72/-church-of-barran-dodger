Purpose

This page records the preservation methodology associated with the author's SHA-256 material dated 30 September 2026.

SHA-256 is a cryptographic hashing function. A hash can provide a reproducible digital fingerprint of a particular file at a particular point in time.

PRESERVATION IS NOT PROOF OF TRUTH

A matching hash can demonstrate that the same digital content was preserved or reproduced. It does not, by itself, establish that the contents of the file are true, that an allegation occurred, or that any person committed wrongdoing.

What SHA-256 Establishes

01

Digital Fingerprint

A SHA-256 hash represents the contents of a particular digital file.

02

Change Detection

A materially changed file will ordinarily produce a different hash.

03

Reproducibility

Anyone with the same file can calculate its hash and compare the result.

04

Preservation

Hashes can contribute to a documented chain showing how digital material was preserved.

What SHA-256 Does Not Establish

Truth

A hash does not prove that the contents of a document are true.

Authorship

A hash alone does not prove who created or authored a document.

Intent

A hash does not establish why a document was created or what a person intended.

Criminal Liability

A hash does not establish that a crime occurred or that a person is legally responsible.

Evidence Classification

A · DOCUMENTED FACT B · CORROBORATED CLAIM C · DOCUMENTED ALLEGATION D · INFERENCE E · SPECULATION

The technical fact that a file possesses a particular SHA-256 hash is distinct from propositions contained within that file.

For example, “this file produced this hash” is a technical preservation proposition. A statement inside the file may require a completely different evidentiary assessment.
